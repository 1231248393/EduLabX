Install:
1. Back up your current college-portal-temp folder.
2. Extract this ZIP.
3. Replace the existing project folder with the extracted college-portal-temp folder.
4. In VS Code terminal, run:
   pnpm install
   pnpm dev
5. Open the local site and hard-refresh the browser with Ctrl+Shift+R.

The TypeScript data file and the edited React component passed syntax transpilation checks. A full Next.js production build was not run in this environment because project dependencies were not installed here.
